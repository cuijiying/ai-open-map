# 运行与接口

## 1. 准备

已在这台机器上验证过的版本：JDK 17、Maven 3.9、Node.js 22、PostgreSQL 16.2、PostGIS 3.4.1。`psql` 默认路径：

```text
C:\Program Files\PostgreSQL\16\bin\psql.exe
```

数据库账号是本地的 `postgres` / `post`。不要把这套口令用于公网。

```powershell
.\scripts\init-db.ps1
mvn -DskipTests package
.\scripts\start-all.ps1
```

`init-db.ps1` 会创建库（如果还没有）并执行 `sql/schema.sql`。`start-all.ps1` 把 `OSM_DATA_DIR` 设为仓库下的 `data\osm`，按端口跳过已经在听的服务，然后启动前端开发服务器。

停止：

```powershell
.\scripts\stop-all.ps1
```

| 地址 | 作用 |
| --- | --- |
| http://127.0.0.1:5173 | 页面 |
| http://127.0.0.1:8080 | 网关，页面的 `/api` 都到这里 |
| http://127.0.0.1:8081/druid/ | 入库服务监控，`admin` / `admin` |
| http://127.0.0.1:8082/druid/ | 地图服务监控 |
| http://127.0.0.1:8083/druid/ | 对话服务监控 |
| http://127.0.0.1:8081/actuator/health | 各服务健康检查，端口换成 8082、8083、8080 |

日志在 `logs/`。这个目录不进 Git。PBF 和 `.md5` 也不进 Git，只保留 `data/osm/.gitkeep`。

第一次打开页面后，左侧任务面板可以手动下载安徽省。已有 `RUNNING` 任务时再次点击会失败。每天 03:00 也会自动跑。下载地址是 Geofabrik，需要能访问外网。

使用地图时保留 OpenStreetMap 署名，数据许可为 ODbL。

## 2. 页面上能做的事

左侧勾选图层。数量来自 `/api/geo/layers`，任务在跑的时候每 2 秒刷新一次日志，结束后重新取数量。

右侧可以直接输入这些话（未配置模型时也有效）：

- 显示道路 / 水系 / 建筑 / 铁路 / 土地利用 / 兴趣点 / 地名 / 行政区划
- 只显示高速公路，或隐藏建筑
- 定位到合肥、黄山、芜湖等安徽城市，以及九华山
- 统计道路数量
- 查找大学
- 分析当前视野内的道路里程
- 重置地图

“高速公路”会显示道路图层，并在前端按 `motorway`、`motorway_link`、`trunk`、`trunk_link` 过滤。“查找大学”是名称模糊匹配，不是只查大学设施。

模型配置弹窗写入 `ai_model_config`。可以先测通再启用。启用后，规则识别不了的句子才会发给模型。

地图上点击要素会弹出名称。搜索结果用标记图层画出来。移动地图时，页面记下当前视野，分析类指令用的就是这个矩形。

## 3. HTTP 接口

除瓦片外，成功响应都是：

```json
{ "code": 0, "message": "ok", "data": {} }
```

失败是 HTTP 400（参数）、409（状态冲突，例如已有任务在跑）或 500，正文 `code` 为 1。

### 入库

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/ingest/regions` | 可下载区域，目前是安徽省 |
| POST | `/api/ingest/jobs` | 正文 `{"regionCode":"anhui"}`，手动开始 |
| GET | `/api/ingest/jobs/latest` | 最近一次任务 |
| GET | `/api/ingest/jobs/{id}/logs?afterId=0` | 该 id 之后的日志 |

### 地图

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/geo/layers` | 九个图层的中文名和数量 |
| GET | `/api/geo/stats?layer=highway` | 该图层子类前 30 名 |
| GET | `/api/geo/search?keyword=合肥&layer=&limit=8` | 名称或子类模糊搜索，最多 30 条 |
| GET | `/api/geo/analyze?layer=highway&minLon=&minLat=&maxLon=&maxLat=` | 与矩形相交的数量、米、平方米 |
| GET | `/api/tiles/{layer}/{z}/{x}/{y}.pbf` | 矢量瓦片，`z` 为 0–16 |

瓦片的 `Content-Type` 是 `application/vnd.mapbox-vector-tile`，缓存 2 分钟。source-layer 名等于图层名。未知图层或越界的 z/x/y 返回空正文，不是 JSON 错误。

低缩放会简化几何，并丢掉过细的子类。建筑、兴趣点从 z=13 才有数据，土地利用从 z=10，水系线从 z=7。这和前端样式的 `minzoom` 对齐。

### 对话

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/ai/models` | 列表，密钥打码 |
| POST | `/api/ai/models` | 新建 |
| PUT | `/api/ai/models/{id}` | 更新；密钥空字符串表示不改 |
| DELETE | `/api/ai/models/{id}` | 删除 |
| POST | `/api/ai/models/{id}/enable` | 启用，并关闭其他模型 |
| POST | `/api/ai/models/test` | 用表单里的地址试一次对话 |
| POST | `/api/ai/chat` | 对话 |

聊天请求：

```json
{
  "messages": [{ "role": "user", "content": "定位到合肥" }],
  "map": {
    "center": [117.28, 31.86],
    "zoom": 6.4,
    "bbox": [114.88, 29.39, 119.65, 34.65],
    "visibleLayers": ["highway", "water"]
  }
}
```

响应里的 `source` 是 `rule` 或 `llm`。`actions` 的 `type` 包括 `show_layers`、`hide_layers`、`only_layers`、`fly_to`、`markers`、`clear_markers`。`tables` 是前端直接渲染的列和行。

## 4. 切换到 Nacos

默认不需要 Nacos。要改成服务发现时：

1. 启动 Nacos，或设置 `NACOS_ADDR`。
2. 四个 Java 进程都加上 `--spring.profiles.active=cloud`。
3. 网关不再写死 `127.0.0.1`，而走 `lb://map-ingest`、`lb://map-geo`、`lb://map-ai`。

对话服务调用地图服务的地址仍是配置项 `app.geo.base-url`（默认 `http://127.0.0.1:8082`）。cloud 模式下如果地图服务端口不固定，需要把这个地址改成经网关或注册中心能解析的地址。0.1 的 cloud 配置没有改这一处。

## 5. 重新编译时注意

父工程没有 main class，不要对根 POM 执行 `spring-boot:run`。打包：

```powershell
mvn -DskipTests package
```

如果某个 jar 正在运行，Windows 会锁住文件，repackage 无法改名。先 `.\scripts\stop-all.ps1`，或只停掉对应端口的进程，再打包、再启动。
