# 智图灵 GeoMind Agent —— 作品定位与能力规划

> 本文档用于公司 AI 创新大赛筹备。后续实现按本规划落地；对外介绍文档按「已实现」口径撰写。

## 1. 作品一句话

**智图灵（GeoMind Agent）**：一套可私有化部署的全栈开源地图智能体——用自然语言驱动 OpenStreetMap 数据入库、矢量地图操控、空间分析与报告生成。

## 2. 作品名称 / 简介 / 应用场景（报送用）

### 作品名称

**智图灵 GeoMind Agent —— 全栈开源地图智能体**

英文副标题：*Open-Source Full-Stack Map Agent for China Provincial OSM*

### 作品简介（约 180 字）

智图灵是面向企业内网与开源社区的全栈地图智能体。系统基于 Spring Cloud 微服务、PostGIS 与 MapLibre，完整覆盖省级 OSM 数据下载解析、多省矢量切片发布与中文对话操控。在规则引擎与大模型之上，构建了「规划—工具调用—执行—反思」的 Agent 闭环：可自动编排入库任务、切换图层与风格、检索要素、视野分析、跨省对比，并输出结构化地图报告。支持 OpenAI 兼容本地/云端模型，数据与推理均可私有化，适合应急、规划、教育与企业 WebGIS 场景。

### 应用场景（报送条目）

1. **应急指挥快速研判**：自然语言圈定受灾视野，统计道路/水系/建筑，标记关键设施。
2. **城市规划与基建盘点**：按图层过滤高速/铁路/用地，跨省对比路网密度与用地结构。
3. **高校 GIS / OSM 教学实验**：一键拉取省级开源地图，对话式完成查询与分析实验。
4. **政企私有化 WebGIS 底座**：无商业底图 Token 依赖，OSM + 本地切片 + Agent 操控。
5. **文旅与区域导览**：定位景点城市、检索 POI、切换影像/纸图风格并生成导览摘要。

## 3. 现状能力（仓库已有）

| 能力层 | 现状 |
| --- | --- |
| 数据 | Geofabrik 省级 PBF 下载、Osmosis 解析、PostGIS 分区发布 |
| 地图 | 九图层矢量切片、多省同图、低缩放预生成、视野分析/搜索/统计 |
| 对话 | 规则优先 + OpenAI 兼容 LLM；动作：图层/定位/标记/风格/着色 |
| 架构 | Gateway + ingest/geo/ai；可选 Nacos；React + MapLibre 前端 |

局限：多为单轮意图识别；LLM 仅输出受限 JSON；缺少多步规划、工具注册、任务记忆、入库编排与报告生成。

## 4. Agent 能力增强规划（后续实现目标）

### 4.1 目标架构：三层智能体

```text
用户自然语言
    │
    ▼
┌─────────────────────────────────────────┐
│  Orchestrator Agent（编排智能体）         │
│  意图分解 / 计划生成 / 工具选择 / 反思重试 │
└───────────────┬─────────────────────────┘
                │ tool calls
    ┌───────────┼───────────┬────────────┐
    ▼           ▼           ▼            ▼
 MapOps     GeoAnalyst   IngestOps    ReportOps
 地图操控    空间分析      入库编排      报告叙事
    │           │           │            │
    └───────────┴───────────┴────────────┘
                      │
              PostGIS / 切片 / 任务表 / 模型
```

### 4.2 核心能力清单

| 编号 | 能力 | 说明 | 依赖 |
| --- | --- | --- | --- |
| A1 | 多步 ReAct 规划 | 复杂指令拆成有序 tool calls，失败可反思重试 | map-ai 会话状态机 |
| A2 | 工具注册中心 | 统一注册 fly/layer/search/analyze/stats/ingest/style/compare/report | ToolSpec + JSON Schema |
| A3 | 地图状态记忆 | 记住当前省份、图层、视野、风格、标记，支持指代消解 | ChatSession + MapContext |
| A4 | 入库 Agent | 「下载浙江并在完成后只显示道路」→ 建任务、轮询、续对话 | ingest API + 异步回调 |
| A5 | 跨省对比分析 | 多省同图层指标并排表格 + 可选飞到差异最大区域 | geo stats/analyze |
| A6 | 空间问答增强 | 组合 search+analyze+paint，突出关键要素着色 | paint_layer + markers |
| A7 | 地图报告生成 | 输出 Markdown/HTML 简报：结论 + 表格 + 建议下一步 | ReportOps |
| A8 | 技能插件（Skills） | 应急/规划/教学等场景提示词与工具白名单可插拔 | skills/*.yml |
| A9 | 本地/云端双模 | Ollama 等本地模型优先；云端兜底；密钥打码 | 现有 LlmClient |
| A10 | 可观测与安全 | 工具调用审计、图层白名单、SQL 仅经服务层 | 日志 + 权限钩子 |

### 4.3 实现阶段建议

1. **阶段一：工具化** —— 把现有 followUp/actions 收拢为 Tool Registry；会话持久化。
2. **阶段二：编排** —— Orchestrator + ReAct；入库异步续聊；跨省对比工具。
3. **阶段三：场景化** —— Skills 插件、报告生成、前端「Agent 思考过程」面板与评测集。

## 6. 演示话术提纲（3 分钟）

1. **痛点**（20s）：传统 WebGIS 操作门槛高；商业地图难私有化；开源 OSM 上手重。
2. **方案**（40s）：智图灵 = 开源地图底座 + 地图 Agent；自然语言驱动全链路。
3. **现场**（90s）：下载省份 → 显示高速 → 分析视野里程 → 跨省对比 → 生成简报。
4. **价值**（30s）：可私有化、可开源复用、可扩展 Skills，服务创新与业务落地。
